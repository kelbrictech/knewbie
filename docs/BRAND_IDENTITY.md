# KNEWBIE visual identity

The public demo and Cloudflare live site use the original KNEWBIE blue mascot alongside the original wordmark in staff/admin headers. The former black KN monogram was removed. Login uses the same mascot, as does the favicon. The demo uses its own checked-in copy of the original PNG at `assets/knewbie-mascot.png`.

The original lesson content and existing user flows are unchanged by this brand update.
